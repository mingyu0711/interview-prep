# 면접 연습 앱

취업·이직 면접을 혼자 준비할 수 있는 웹 애플리케이션입니다.  
직접 질문을 등록하고, 랜덤으로 질문을 받으며 답변을 녹음·저장할 수 있습니다.

## 시작하기

```bash
npm install
npm run dev
```

`http://localhost:5173` 접속

---

## 사용법

### 1단계 — 질문 등록

질문을 두 가지 방법으로 등록할 수 있습니다.

**직접 입력**  
카테고리를 선택하고 질문을 입력한 뒤 `Enter` 또는 추가 버튼을 누릅니다.

**파일 업로드**  
`.txt` 파일을 업로드합니다. 한 줄에 질문 하나씩 작성하면 됩니다.  
카테고리를 지정하려면 `카테고리::질문` 형식을 사용합니다.

```
프론트엔드::클로저란 무엇인가요?
CS/자료구조::스택과 큐의 차이를 설명해주세요.
행동면접::본인의 강점과 약점을 말해주세요.
```

등록된 질문은 목록에서 편집·삭제할 수 있으며, 새로고침 후에도 유지됩니다.

---

### 2단계 — 면접 시작

카테고리 탭에서 원하는 분야를 선택하면 해당 카테고리 질문만으로 면접을 진행할 수 있습니다.  
**면접 시작** 버튼을 누르면 질문이 랜덤으로 출제됩니다.

---

### 3단계 — 세션 진행

- **녹음 시작** 버튼으로 답변을 녹음합니다.
- 녹음 중 일시정지·재개가 가능합니다.
- 중지 후 **파일 저장**을 누르면 저장 경로를 직접 지정해 `.webm` 파일로 저장할 수 있습니다.
- 모든 질문이 끝나면 완료 화면이 나타나며, 다시 시작하거나 종료할 수 있습니다.

| 단축키 | 동작 |
|--------|------|
| `→` 또는 `N` | 다음 질문 |
| `Space` | 녹음 토글 |
